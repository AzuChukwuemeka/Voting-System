# Voting System (Node.js + EJS + MongoDB)

A simple voting system built using **Node.js**, **Express**, **EJS**, and **MongoDB**. This project is created for learning purposes and demonstrates the use of server-side rendering with persistent data storage.

## Features

- Clean and dynamic UI using EJS templates
- MongoDB-based vote storage for persistence
- Add and vote for predefined options
- Real-time vote count updates on page refresh
- Simple and secure form handling

## Tech Stack

- **Backend**: Node.js, Express.js
- **Frontend**: EJS, HTML, CSS
- **Database**: MongoDB
- **Templating Engine**: EJS
- **ORM**: Mongoose

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/)
- [MongoDB](https://www.mongodb.com/) (local or Atlas)
- [Git](https://git-scm.com/)

### Installation

1. **Clone the repository**
   2. Install dependencies
   3. Use nodemon run
